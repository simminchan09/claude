# Eclipse Duel (이클립스 듀얼)

브라우저에서 바로 실행되는 1:1 대전 액션 게임입니다. `duel/index.html` 파일 하나로 동작하며 외부 이미지·사운드 에셋이 없습니다 (Canvas 2D + Web Audio로 모두 직접 그림/합성).

## 캐릭터
| | 카이렌 (뇌명의 검성) | 벨로나 (홍염의 여제) |
|---|---|---|
| 무기 | 뇌도 「시라누이」 (카타나) | 염겸 「아스트레아」 (대낫) |
| 약공 J ×3 | 삼연 뇌참 (마지막 찌르기가 띄움) | 참격 2연 + 회전베기 |
| 강공 K | 승룡참 (올려베기) | 염륜참 (도약 내려찍기 폭염) |
| S1 L | 뇌섬: 관통 돌진 | 홍련구: 화염구 |
| S2 U | 천뢰강림: 낙뢰 3연 | 염화진: 불기둥 5연 |
| 궁극기 I | **뇌신강림**: 10연참 → 발도 일섬 → 뇌주 | **종언의 홍염**: 불사조 소환 → 급강하 폭발 |

궁극기는 에너지 100%에서 사용하며, 컷인 애니메이션(초상화 배너 + 기술명) 후 전용 연출이 나옵니다.

## 조작
| | 1P | 2P |
|---|---|---|
| 이동 / 점프 / 방어 | A D / W / S | ← → / ↑ / ↓ |
| 대시 | Space | 넘패드 0 |
| 약공 · 강공 · S1 · S2 · 궁 | J K L U I | 넘패드 1 2 3 4 5 (또는 , . / ; ') |

1P vs CPU 모드에서는 방향키와 Z X C V B도 사용 가능합니다. Esc/P 일시정지, M 소리 켜기/끄기. 모바일에서는 화면 하단 터치 패드가 표시됩니다.

## 시스템
- 3판 2선승, 라운드 99초
- 약공 연타 콤보, 적중 시 강공·스킬로 캔슬 가능, 콤보 데미지 보정
- 방어(정면 공격 88% 감소), 대시(짧은 무적), 띄우기 → 다운 → 기상 무적
