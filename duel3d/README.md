# Eclipse Duel 3D

1:1 3D 대전 액션 게임의 시스템과 맵입니다. Three.js(`../lib/three.module.js`)만 사용하며 빌드 과정이 없습니다.
지금은 시스템 확인용 캐릭터 **훈련 기체 TB-01** 하나만 들어 있고, 정식 캐릭터는 `CHARACTER_GUIDE.md`에 따라 하나씩 추가합니다.

## 실행
저장소 루트에서 정적 서버를 띄우고 `/duel3d/`를 엽니다 (ES 모듈이라 `file://`로는 브라우저에 따라 안 열릴 수 있음).
```
python3 -m http.server 8000   # → http://localhost:8000/duel3d/
```

## 구현된 시스템
| 분류 | 내용 |
|---|---|
| 모드 | 1P vs CPU · 2P 로컬 대전 · 훈련 모드(무한 시간, 더미 행동 3종, 단축키) |
| 경기 | 3판 2선승, 라운드 99초, KO/타임오버/무승부, 라운드 인트로·승리 연출·결과 화면 |
| 카메라 | 내 캐릭터 등 뒤(어깨 너머)에서 상대를 바라보는 3인칭 추적 카메라, 2P 대전은 좌우 화면 분할 (궁극기·KO·결과 연출 중에는 전체 화면) |
| 이동 | 카메라 기준 8방향 이동, 점프·공중 제어, 대시(짧은 무적), 반경 21m 결투장 경계 |
| 지형 | 맵마다 장애물 충돌, 낮은 장애물 위에 올라서기, 장애물에 세게 날아가면 튕김, 투사체가 장애물에 막힘, 시야를 가리는 장애물 반투명, 위험 지대(용암) |
| HUD | 오버워치식: 내 체력 왼쪽 아래 · 궁극기 원형 게이지 가운데 아래 · 스킬 쿨타임 오른쪽 아래 · 상대 체력은 머리 위 |
| 전투 | 데이터 기반 기술(키프레임 포즈·히트 구체·이벤트·전진), 약공 3연타, 적중 시 강공·스킬 캔슬 |
| 판정 | 구체 vs 캡슐 피격, 정면 방어(데미지 88% 감소·방어막), 띄우기→다운→기상 무적, 콤보 보정 |
| 자원 | 에너지(시간·타격·피격으로 충전) → 궁극기, 스킬 2종 쿨타임 |
| 궁극기 | 화면 고정 + 3D 초상 컷인 배너 → 카메라 시네마틱 키프레임 → 상대 고정/해제 |
| 연출 | 히트스톱, 화면 흔들림, 슬로모션, 화면 섬광, 하늘 색조, 데미지 숫자, 콤보 카운터 |
| 이펙트 | GPU 파티클(불꽃·빛·불씨·연기·먼지), 참격 초승달, 충격파 링, 빛기둥, 순간 광원, 무기 궤적 |
| AI | 거리별 행동, 방어 반응, 연타 이어가기, 스킬·궁극기 사용, 장애물 회피(뛰어넘기·돌아가기) |
| 기타 | 합성 사운드, 터치 패드(모바일), 일시정지 |

## 맵 (10종)
게임을 시작할 때마다 10곳 중 하나가 무작위로 정해집니다(직전 맵 제외). 맵 이름은 1라운드 시작 때 표시됩니다.
결투장 안에는 컨셉에 맞는 장애물이 있고, 중앙과 두 시작 위치는 비어 있습니다.

| # | 맵 | 결투장 안 오브젝트 |
|---|---|---|
| 1 | 일식의 신전 | 석주와 부러진 그루터기, 제단 2개(올라서기), 쓰러진 석주, 석등 4기 |
| 2 | 붉은 모래 협곡 | 바위 기둥, 무너진 성벽(높은 벽·낮은 벽), 오벨리스크, 쓰러진 오벨리스크, 선인장, 낮은 바위 |
| 3 | 빙설 요새 | 얼음 결정 무리, 눈 쌓인 요새 벽, 보급 상자(쌓인 것 포함), 눈더미, 화로 |
| 4 | 바람의 평원 | 거석 3쌍, 큰 나무, 건초더미, 넘을 수 있는 울타리, 우물 |
| 5 | 노을빛 해상 | 범선 갑판: 돛대 2개, 화물 상자·통, 대포, 고물 갑판 단(올라서기) |
| 6 | 용암 분화구 | 계단식 현무암 기둥, 흑요석 가시, 용암 웅덩이(서 있으면 피해) |
| 7 | 천봉 정상 | 바위 노두, 불탑(기단 올라서기), 돌탑, 룽다 깃발 장대 |
| 8 | 죽림 사당 | 대나무 덤불 7곳, 석등, 잉어 연못, 쓰러진 대나무 다발 |
| 9 | 네온 시티 옥상 | 공조기(팬 회전), 기둥 위 물탱크, 환기구, 네온 광고판 벽, 빛나는 상자 |
| 10 | 궤도 성역 | 수정 기둥, 무너진 아치, 대리석 블록 계단, 수정 받침대 |

맵 추가: `src/maps/index.js`의 `MAPS`에 `{ id, name, concept, build(K) }`를 넣으면 무작위 후보에 들어갑니다. 결투장 안 장애물은 `K.cylS` · `K.boxS` · `K.rockS` · `K.colC` · `K.colB`, 위험 지대는 `K.hazard`로 만듭니다. `K`는 `src/maps/kit.js`의 도구 모음입니다
(`sky` · `fog` · `lights` · `arena` · `ground` · `water` · `lava` · `cloudSea` · `mountains` · `inst` · `weather` · `point` 등).

## 조작
| | 1P (키보드 + 마우스) | 2P (키보드) |
|---|---|---|
| 이동 | W A S D (1인 모드는 방향키도) | 방향키 |
| 기본공격 (연타 3단) | 좌클릭 | Num1 |
| 스킬 | 우클릭 · Shift · E | Num2 · Num4 · Num5 |
| 궁극기 | Q | Num6 |
| 점프 / 대시 / 방어 | Space / C / F | Num0 / Num. / Num3 |

`J K U I O`도 1P의 기본공격·스킬·궁극기로 쓸 수 있습니다. `Esc`/`P` 일시정지, `M` 소리.
훈련 모드: `1` 궁극기 충전 · `2` 쿨타임 초기화 · `3` 체력 회복 · `4` 더미 행동 변경.
