# Eclipse Duel 3D

명조·젠레스 존 제로식 3D 액션 전투 게임의 시스템과 맵입니다. Three.js(`../lib/three.module.js`)만 사용하며 빌드 과정이 없습니다.

## 액션 전투 시스템
기본공격(좌클 연격과 그 탄)은 피해만 준다 — 맞은 상대가 경직되거나 밀려나거나 넘어지지 않고, 그로기(브레이크) 게이지도 쌓이지 않는다. 경직 · 넉백 · 띄우기는 스킬 · 낙하 공격 · 반격 · 궁극기에만 있다.
궁극기 게이지가 차는 속도는 모든 캐릭터 공통으로 ×0.5 (`fighter.js` 의 `ULT_GAIN` — 시간 · 때리기 · 맞기 · 방어 · 패리 모두 적용).

선택 화면은 오버워치식입니다: 모드를 고르면 화면 아래에 캐릭터 초상화 아이콘 줄이 나오고(초상화는 각 캐릭터 얼굴을 실시간으로 한 번씩 렌더해 만듦), 위쪽 탭(1P / 상대)으로 어느 쪽을 고를지 정합니다. 고른 캐릭터 이름 · 설명 · 기술표는 왼쪽, 3D 모델은 배경에 크게 보입니다.

모든 캐릭터 얼굴은 이목구비(눈 · 눈썹 · 코 · 입) 없이 민얼굴입니다 — `src/face.js` 의 `FACE_FEATURES = false` (true 로 바꾸면 다시 그림).

차징 기술: 기술 정의에 `hold: { key, at, max }` 를 넣으면 `at` 시점에서 버튼을 누르고 있는 동안 기술 시간이 멈추고 힘이 모입니다(`f.holdK` 0~1). 제이 · 오로라의 우클 저격이 차징식(짧게 ×0.7 ~ 완충 ×1.6)이고, 아자젤의 사슬 낚아채기 사거리는 16m 입니다.

피해 밸런스는 `src/balance.js` 의 `BALANCE` 표(캐릭터별 · 기술 분류별 배율)로 맞춥니다. 분류(light/heavy/s1/s2/ult/counter/plunge)는 기술을 시작할 때 정해지고 그 기술이 만든 투사체 · 소환물 · 장판 피해에도 그대로 적용됩니다. 기준: 근접 4연타 합 ≈ 175~185 · 원거리 4연타 ≈ 150 · 강공격 ≈ 90~105 · 궁극기 ≈ 275~290 · 체력 880(원거리)~1150(탱커).

|---|---|
| 자유 시점 | 마우스로 카메라 회전(클릭하면 포인터 잠금, Esc로 해제·일시정지). 공격은 화면 앞쪽 가까운 적에게 자동 조준 |
| 대상 고정 | `Tab` 또는 휠 클릭. 고정 중에는 카메라가 대상 쪽으로 돈다 |
| 극한 회피 | `C` 회피 직후(0.2초 안)에 맞을 공격이면 발동 → 적 전체가 1.7초간 느려지고, 그 사이 좌클릭은 순간이동 반격 |
| 패리 | `F`(또는 마우스 옆 버튼 뒤) 방어를 누른 직후(0.22초 안)에 막으면 발동 → 피해 없음, 상대 공격 끊김 · 그로기 크게 증가 |
| 공격 예고 | 적이 공격 전에 빛난다. **노랑** = 패리 가능, **빨강** = 막을 수 없음(회피해야 함) |
| 그로기 · 브레이크 | 적마다 그로기 게이지. 가득 차면 브레이크(3~5초 무력화, 받는 피해 1.5배) |
| 슈퍼아머 | 파쇄자 · 보스는 브레이크 전까지 맞아도 경직되지 않음 |
| 치명타 | 플레이어 공격 20% 확률로 1.6배 |
| 동시 공격 제한 | 잡몹은 최대 2마리까지만 동시에 공격 |

## 구현된 시스템

## 조작
| | 1P (키보드 + 마우스) | 2P (키보드) |
|---|---|---|
| 이동 | W A S D (1인 모드는 방향키도) | 방향키 |
| 기본공격 (연타 3단) | 좌클릭 | Num1 |
| 스킬 | 우클릭 · Shift · E | Num2 · Num4 · Num5 |
| 궁극기 | Q | Num6 |
| 점프 / 회피 / 방어 | Space / C·마우스 옆 버튼(앞) / F·마우스 옆 버튼(뒤) | Num0 / Num. / Num3 |
| 앉기 (누르고 있기) | 좌 Ctrl (전투 중 Ctrl+W 는 브라우저 탭 닫기라 나가기 확인 창이 뜸) | Num7 |

`J K U I O`도 1P의 기본공격·스킬·궁극기로 쓸 수 있습니다. `Esc`/`P` 일시정지, `M` 소리.
