# Eclipse Duel 3D

명조·젠레스 존 제로식 3D 액션 전투 게임의 시스템과 맵입니다. Three.js(`../lib/three.module.js`)만 사용하며 빌드 과정이 없습니다.
정식 캐릭터 **레오 폰 아이젠가르트**(GLAIVIER) · **아자젤**(OVERLORD) · **아리엘**(AQUARIST)과 시스템 확인용 **훈련 기체 TB-01**이 들어 있고, 나머지 캐릭터는 `CHARACTER_GUIDE.md`에 따라 하나씩 추가합니다.

## 캐릭터: 아리엘 (`src/characters/aquarist.js`, 모델 `aquarist_model.js`)
"잃어버린 마력, 꼭 되찾을 거야!" — 원거리 · 물 마법 · 견제. 낙천적이고 호기심 많은 소녀로, 바다 정령의 힘을 빌려 원거리 마법을 쓴다 (누군가에게 마력 일부를 빼앗겨 되찾기 위해 여행 중). 거리를 벌리고 쏘는 첫 원거리 캐릭터 — 기본 공격 중에도 절반 속도로 움직이며 쏠 수 있다.

| 입력 | 기술 | 내용 |
|---|---|---|
| 좌클 ×4 | 물방울 연사 | 물방울 탄 24 → 쌍둥이 물방울(왼손) 17×2 → 물보라 부채(5발) 14 → 버블 버스트(큰 거품 40 · 터지며 범위 28, 띄움). 모두 유도탄, 사거리 30m |
| 공중 좌클 | 낙하 공격 | 지팡이를 아래로 겨누고 내리꽂아 물보라 충격파 66 |
| 우클 | 아쿠아 랜스 (6초) | 물을 모아 관통하는 물의 창을 던짐 72 (멀리까지 · 여러 명 관통) |
| Shift | 버블 프리즌 (10초) | 거품 구슬: 맞으면 1.7초 동안 거품에 갇혀 떠오름(그동안 추가타 가능) → 터지며 54 |
| E | 해류 소용돌이 (12초) | 상대 발밑에 소용돌이: 빨아들이며 0.22초마다 8 → 끝에 물기둥 58(띄움) |
| Q | 바다 정령의 해일 | 해일이 덮치고(90) → 물의 고래가 땅속에서 솟구쳐 상대를 휩쓸어 올리고(110) → 내리꽂힘(150) |
| 고유 | 조류 | 맞힐수록 쌓임(HP 아래 게이지) → 가득 차면 8초 만조: 공격력 ×1.15, 물방울 탄마다 작은 유도탄 추가, 보석이 빛남 |
| C (타이밍) | 극한 회피 반격 | 제자리 물폭발 46 + 뒤로 순간이동하며 유도탄 셋 |
| 대기 | — | 4초간 가만히 있으면 지팡이에 기대 한쪽 다리를 접고 윙크 (승리 자세도 윙크 + 브이) |

모델: 금 별 문장과 아쿠아마린·갈색 리본이 달린 큰 하늘색 마녀 모자(물결 챙 · 검은 안쪽 · 뒤로 휜 끝), 웨이브진 긴 주황빛 금발(뒤 7가닥 + 앞 2가닥 로프 물리, 납작한 리본 관), 호박색 눈, 레이스 칼라와 아쿠아마린 브로치, 흰 실크 블라우스(진주 단추), 금테·금별 파란 케이프렛, 비치는 레이스 퍼프 소매와 손등을 덮는 파란 나팔 커프스, 앞을 끈으로 엮은 갈색 코르셋 + 금 고리 벨트, 검은 플레어 치마 + 흰 프릴 페티코트 두 단(다리를 따라 출렁임), 금별이 박힌 파란 연미 자락(천 물리 · 뾰족한 네 갈래 밑단), 시선 각도에 따라 비치는 검은 스타킹(셰이더), 금색 하이힐, 덩굴·초승달·별로 꾸민 금빛 지팡이와 큰 아쿠아마린(마법을 쓰면 발광). CPU 는 `aiRange` 로 5~12m 거리를 유지하며 쏜다.

## 캐릭터: 아자젤 (`src/characters/azazel.js`, 모델 `azazel_model.js`)
"차별이라는 사슬을 끊어내고, 잃어버린 마족의 영광을 되찾겠어." — 근거리 · 난타 · 화염. 철퇴·발차기·박치기로 들이받는 양키 싸움꾼 (레오의 우아한 글레이브 궤적과 대비되는 거친 근접 난타 스타일).

| 입력 | 기술 | 내용 |
|---|---|---|
| 좌클 ×4 | 싸움꾼 콤보 | 한 손 내리치기 42 → 앞차기 40 → 어깨 몸통박치기 48 → 타자 자세에서 두 손 홈런 스윙 80 (멀리 날림) |
| 공중 좌클 | 낙하 공격 | 불붙은 철퇴로 낙하 강타 · 화염 폭발 76 |
| 우클 | 사슬 낚아채기 (7초) | 손목 사슬을 던져 끌어온 뒤 박치기 70, 기절 |
| Shift | 양키 돌격 (9초) | 철퇴를 바닥에 끌며 돌진(불타는 자국이 남아 밟으면 화상) → 골프 스윙으로 띄움 64 |
| E | 마족의 숨결 (11초) | 숨을 들이켰다가 입으로 부채꼴 화염 방사 (0.12초마다 12) |
| Q | 마왕 각성 | 기를 모았다가 터뜨림(반경 4.8m, 가까울수록 90~200 · 띄움) → 15초 각성 — 공격력 ×1.3 · 이동 속도 ×1.25 · 받는 피해 ×0.75 · 쿨타임 회복 ×1.6.  족쇄 사슬이 끊어지고 뿔·눈·철퇴가 불타오름 |
| 고유 | 열기 | 때릴수록 쌓임(HP 아래 게이지) → 가득 차면 8초 발화: 철퇴에 불이 붙고 공격력 ×1.15 |
| C (타이밍) | 극한 회피 반격 | 순간이동 드롭킥 + 폭발 |
| 대기 | — | 4초간 가만히 있으면 양키 쪼그려 앉기 |

모델: 빨간 단발(오른쪽 눈을 덮는 앞머리) + 허벅지까지 오는 땋은 머리(로프 물리), 마디진 검은 뿔(각성 시 균열 발광), 뾰족 귀, 볼 반창고, 철 목줄의 십자 문장, 세운 깃에 흰 털이 달린 크롭 재킷(왼팔 불꽃 긴소매·오른팔 LORD 패치 반소매), 붕대 상의와 붉은 스카프, 손목·발목 족쇄에 매달려 흔들리는 끊어진 사슬, 벨트·사슬·악마 키링(흔들림), 다리를 따라 출렁이는 칼주름 롱스커트(앞트임 · 「不条理の鎖を喰いちぎれ」 글귀 · 등 뒤 「魔」 천), 니삭스, 하이탑 운동화, 붉은 구름 무늬의 가시 철퇴(삼지창 끝 · 갈고리 날 · GRIGORI 명판).

## 캐릭터: 레오 폰 아이젠가르트 (`src/characters/leo.js`)
"짐은 감히 누구도 쳐다볼 수 없는 '절대적인 공포'다!" — 근거리 · 물리 · 브루저. 거대한 글레이브로 넓게 쓸어 버리는 찬탈한 왕.

| 입력 | 기술 | 내용 |
|---|---|---|
| 좌클 ×4 | 기본 공격 | 올려베기 44 → 머리 위 내려찍기 48 → 한 바퀴 회전 베기 56 → 돌진 찌르기 72 (설정화 Action 1) |
| 공중 좌클 | 낙하 공격 | 창을 치켜들었다 내리꽂으며 낙하(경로 34) → 착지 충격파 반경 2.6m 78, 띄움 · 땅 갈라짐 |
| 우클 | 오만한 반격 (18초) | 1.5초 방어 태세: 푸른 방벽, 앞쪽 피해 50% 감소·경직 없음. 맞거나 다시 누르면 「꺼져라!」 반격 185 (Action 3) |
| Shift | 난도질 (9초) | 좌우로 2회 휘두르기 42·50 → 머리 위에서 내려베기 89, 땅이 갈라지며 넘어뜨림 |
| E | 파괴의 투창 (14초) | 조준한 곳으로 창을 던짐: 경로 피해 32 → 꽂히며 금빛 갈라짐 + 푸른 반구 충격파 반경 4m 154, 띄움 → 창이 손으로 돌아옴 (Action 2) |
| Q | 절대적인 공포 | 하늘의 왕관 인장 → 도약 → 내리꽂기 150 + 빛기둥 → 뽑아 올려베기 160, 전용 카메라 연출·컷인 |
| C (타이밍) | 극한 회피 반격 | 순간이동 돌진 찌르기 96 |

모델(`src/characters/leo_model.js`): 기본 도형을 쌓지 않고 `src/sculpt.js`의 곡면 도구로 만든 고해상도 모델입니다.
- 비율: 약 8등신(키 2.2m), 긴 다리·넓은 어깨. 팔다리는 근육 굴곡이 있는 해부학 단면 로프트 위에 판금 갑옷을 겹쳤습니다.
- 얼굴: 구 하나를 조각한 곡면(눈두덩·광대·콧대·콧망울·각진 턱) + 눈꺼풀이 내려온 날카로운 눈매, 굵은 흰 눈썹.
- 머리카락·수염: 뒤로 넘긴 두피 덮개 + 머리칼 결 텍스처를 입힌 머리 다발, 턱을 감싸는 수염 곡면과 콧수염 가닥.
- 흰 털 목도리: 굵기가 변하는 털 관 + 털 묶음 카드 760장 (오른쪽 어깨를 크게 덮음).
- 갑옷: 금 상감을 노멀맵으로 양각한 가슴판·겹판 어깨갑옷·종 모양 손목갑·사바톤, 모든 판 가장자리에 금테. 손가락까지 말아 쥔 주먹.
- 왕관: 뾰족한 테를 한 장의 곡면으로, 루비·사파이어 카보숑. 글레이브: 말린 금 코등이, 가장자리로 갈수록 얇아지는 칼날, 가죽 나선 감개.
- 망토: 13×22 천 시뮬레이션, 벨벳 광택 재질.
- 렌더: 내부 해상도 1.25배 이상(일반 모니터 계단 현상 감소), 그림자가 싸움 위치를 따라가며 3072px 로 선명하게. 저사양은 주소 뒤에 `?q=low`.

## 실행
저장소 루트에서 정적 서버를 띄우고 `/duel3d/`를 엽니다 (ES 모듈이라 `file://`로는 브라우저에 따라 안 열릴 수 있음).
```
python3 -m http.server 8000   # → http://localhost:8000/duel3d/
```

## 액션 전투 시스템
| 시스템 | 내용 |
|---|---|
| 자유 시점 | 마우스로 카메라 회전(클릭하면 포인터 잠금, Esc로 해제·일시정지). 공격은 화면 앞쪽 가까운 적에게 자동 조준 |
| 대상 고정 | `Tab` 또는 휠 클릭. 고정 중에는 카메라가 대상 쪽으로 돈다 |
| 극한 회피 | `C` 회피 직후(0.2초 안)에 맞을 공격이면 발동 → 적 전체가 1.7초간 느려지고, 그 사이 좌클릭은 순간이동 반격 |
| 패리 | `F` 방어를 누른 직후(0.22초 안)에 막으면 발동 → 피해 없음, 상대 공격 끊김 · 그로기 크게 증가 |
| 공격 예고 | 적이 공격 전에 빛난다. **노랑** = 패리 가능, **빨강** = 막을 수 없음(회피해야 함) |
| 그로기 · 브레이크 | 적마다 그로기 게이지. 가득 차면 브레이크(3~5초 무력화, 받는 피해 1.5배) |
| 슈퍼아머 | 파쇄자 · 보스는 브레이크 전까지 맞아도 경직되지 않음 |
| 치명타 | 플레이어 공격 20% 확률로 1.6배 |
| 동시 공격 제한 | 잡몹은 최대 2마리까지만 동시에 공격 |

## 구현된 시스템
| 분류 | 내용 |
|---|---|
| 모드 | 1P vs CPU · 2P 로컬 대전 · 훈련 모드(무한 시간, 더미 행동 3종, 단축키) |
| 경기 | 3판 2선승, 라운드 99초, KO/타임오버/무승부, 라운드 인트로·승리 연출·결과 화면 |
| 카메라 | 내 캐릭터 등 뒤(어깨 너머)에서 상대를 바라보는 3인칭 추적 카메라, 2P 대전은 좌우 화면 분할 (궁극기·KO·결과 연출 중에는 전체 화면) |
| 이동 | 카메라 기준 8방향 이동, 점프·공중 제어, 대시(짧은 무적), 반경 21m 결투장 경계 |
| 낙하 공격 | 모든 캐릭터 공통: 공중(지면에서 0.55m 이상)에서 좌클릭 → 잠깐 떠올랐다가 가까운 상대 쪽으로 내리꽂고, 착지하며 범위 충격파(띄움) |
| 앉기 | 모든 캐릭터 공통: 누르고 있는 동안 몸을 낮춰 피격 캡슐도 낮아짐 → 높은 공격(올려베기 등)이 머리 위로 빗나감. 천천히 이동 가능, 앉은 채로 공격하면 바로 일어나며 공격 |
| 피격 판정 | 무기 선분이 몸 캡슐을 스친 경우 + 이번 프레임에 무기 끝이 쓸고 지나간 수평 부채꼴 안에 몸이 있고 높이가 겹치는 경우(근접 보정). 높이 뜬 상대는 무기가 그 높이까지 오지 않으면 맞지 않음 |
| 기술 중 이동 | 모든 캐릭터 공통: 공격·스킬을 쓰는 동안에도 방향키로 천천히(이동 속도의 28%) 움직일 수 있음. 돌진 구간 · 궁극기 · 공중에서는 제외, 바라보는 방향은 유지 |
| 다운 · 기상 | 띄워져 떨어지면 0.38초 다운(무적 0.7초) 후 빠르게 일어남 |
| 지형 | 맵마다 장애물 충돌, 낮은 장애물 위에 올라서기, 장애물에 세게 날아가면 튕김, 투사체가 장애물에 막힘, 시야를 가리는 장애물 반투명, 위험 지대(용암) |
| HUD | 오버워치식: 내 체력 왼쪽 아래 · 궁극기 원형 게이지 가운데 아래 · 스킬 쿨타임 오른쪽 아래 · 상대 체력은 머리 위 |
| 전투 | 데이터 기반 기술(키프레임 포즈·히트 구체·이벤트·전진), 약공 3연타, 적중 시 강공·스킬 캔슬 |
| 판정 | 골격을 따라가는 부위별 피격 캡슐(머리·몸통·팔·다리), 무기 공격은 칼날이 지나간 경로로 판정, 지면 충격파는 땅 근처만, 정면 방어(데미지 88% 감소), 띄우기→다운→기상 무적, 콤보 보정 · 훈련 모드 `5`(어디서나 `F3`)로 히트박스 보기 |

| 궁극기 | 화면 고정 + 3D 초상 컷인 배너 → 카메라 시네마틱 키프레임 → 상대 고정/해제 |
| 연출 | 히트스톱, 화면 흔들림, 슬로모션, 화면 섬광, 하늘 색조, 데미지 숫자, 콤보 카운터 |

## 맵 (10종)

## 조작
| | 1P (키보드 + 마우스) | 2P (키보드) |
|---|---|---|
| 이동 | W A S D (1인 모드는 방향키도) | 방향키 |
| 기본공격 (연타 3단) | 좌클릭 | Num1 |
| 스킬 | 우클릭 · Shift · E | Num2 · Num4 · Num5 |
| 궁극기 | Q | Num6 |
| 점프 / 회피 / 방어 | Space / C / F | Num0 / Num. / Num3 |
| 앉기 (누르고 있기) | X (또는 Z) | Num7 |
| 시점 · 대상 고정 | 마우스 · Tab / 휠 클릭 | (자동 추적) |

`J K U I O`도 1P의 기본공격·스킬·궁극기로 쓸 수 있습니다. `Esc`/`P` 일시정지, `M` 소리.
훈련 모드: `1` 궁극기 충전 · `2` 쿨타임 초기화 · `3` 체력 회복 · `4` 더미 행동 변경 · `5` 히트박스 보기 (`F3`은 모든 모드).
