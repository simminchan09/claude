# 바람의 대지 (Wildwind)

모바일 브라우저에서 바로 플레이할 수 있는 3D 오픈월드 어드벤처 게임입니다.
『젤다의 전설 야생의 숨결』 스타일의 게임플레이(자유 등반, 패러글라이더, 기력 게이지, 사당, 탑)를
**오리지널 에셋과 코드**로 구현했습니다. (Three.js 기반, 빌드 과정 없음)

## 기능
- 800m × 800m 절차적 생성 섬 (산, 숲, 호수, 설산)
- 어디든 등반 가능한 가파른 지형과 탑, 기력(스태미나) 휠
- 패러글라이더 활공, 낙하 대미지, 수영/익사
- 사과 채집·먹기로 회복, 적(도깨비) 전투
- 사당 8곳의 시련(수호자 처치) → 하트 그릇 / 기력 강화 보상
- 탑 활성화 시 주변 사당이 지도에 표시
- 낮/밤 순환(밤에는 적이 더 공격적), 미니맵·전체 지도
- 자동 저장(localStorage), PWA(홈 화면에 추가 · 오프라인 플레이)

## 조작
| 모바일 | 키보드 | 동작 |
|---|---|---|
| 왼쪽 화면 드래그 | WASD / 방향키 | 이동 |
| 오른쪽 화면 드래그 | 마우스 드래그 | 시점 회전 |
| 점프 | Space | 점프 / 공중에서 다시 누르면 활공 / 등반 중 도약 |
| 달리기 (누르고 있기) | Shift | 달리기 / 빠른 수영 |
| 공격 | J | 검 공격 / 등반 중 손 놓기 |
| 상호작용 | E | 사당 시련 시작, 탑 활성화 |
| 🍎 | Q | 사과 먹기 (하트 1칸 회복) |
| 지도 | M | 전체 지도 |

## 실행 방법
정적 파일만 있으면 됩니다. ES 모듈을 쓰므로 `file://`이 아닌 웹 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# 같은 Wi-Fi의 휴대폰에서 http://<PC의 IP>:8000 접속
```

### GitHub Pages로 휴대폰에서 플레이
1. 저장소 **Settings → Pages** 에서 Source를 이 브랜치(루트 `/`)로 지정
2. `https://<사용자명>.github.io/<저장소명>/` 접속
3. 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 전체화면으로 실행됩니다

## 파일 구성
- `index.html`, `style.css` — 화면/터치 UI
- `game.js` — 게임 전체 로직 (지형 생성, 물리, 적 AI, HUD)
- `lib/` — Three.js r186 (MIT 라이선스)
- `manifest.json`, `sw.js`, `icon.svg` — PWA
